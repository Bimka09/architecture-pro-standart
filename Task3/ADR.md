### <a name="_qmphm5d6rvi3"></a>**Решение**
Для реализации функционала открытия депозитов была выбрана микросервисная архитектура. Приложеные диаграммы описывают структуру системы и ее окружение:

1. [C4 Context](../diagrams/Context.puml)
2. [C4 Container](../diagrams/Containers.puml)

Ключевыми принципами архитектурного решения являются:
    1. Минимизация нагрузки на АБС
    2. Асинхронное взаимодействие через брокер сообщений Kafka
    3. Отсутствие прямых вызовов интернет-банка и сайта к API АБС
    4. Выделение инфраструктурных и интеграционных сервисов в отдельные компоненты
    5. Горизонтальное масштабирование всех компонентов, кроме АБС
