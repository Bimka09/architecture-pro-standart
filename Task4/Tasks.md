# Требования к архитектуре и сервисам онлайн-депозитов

| **№** | **Требования** | **Система** |
| :-: | --- | --- |
| 1 | Развернуть инфраструктуру Kafka как основной брокер сообщений:<br>– Настроить Kafka-кластеры;<br>– Создать топики: заявки на депозиты, обновления ставок, уведомления | Kafka |
| 2 | Реализовать API Gateway:<br>– Авторизация и аутентификация;<br>– Маршрутизация запросов сайта и интернет-банка;<br>– Централизованное логирование и мониторинг | API Gateway |
| 3 | Добавить на сайт функциональность подачи заявки на депозит для новых клиентов:<br>– Валидация вводимых данных;<br>– Взаимодействие с API Gateway | Сайт банка |
| 4 | Реализовать сервис обработки заявок на открытие депозита (Deposit Processing Service):<br>– Приём заявок с сайта;<br>– Сохранение заявок в БД (MS SQL);<br>– Публикация события о новой заявке в Kafka | Deposit Processing Service |
| 5 | Реализовать функциональность интернет-банка:<br>– Отображение списка депозитов;<br>– Отображение персонализированных ставок;<br>– Подача заявки на депозит;<br>– Выбор счёта и суммы;<br>– Вызов метода создания заявки;<br>– Подтверждение операции через SMS | Интернет-банк |
| 6 | Реализовать сервис управления ставками (Rate Management Service):<br>– Подключение БД для хранения ставок (MS SQL);<br>– Расчёт персонализированных ставок;<br>– Получение данных из АБС (общие и клиентские);<br>– Асинхронное взаимодействие через Kafka | Rate Management Service |
| 7 | Реализовать сервис интеграции (Integration Service):<br>– SFTP-интеграция с партнёрским кол-центром;<br>– Асинхронное взаимодействие с Kafka;<br>– Интеграция с АБС | Integration Service |
| 8 | Реализовать сервис уведомлений (Notification Service):<br>– Асинхронное взаимодействие с Kafka;<br>– Интеграция с SMS-шлюзом телеком-оператора | Notification Service |
